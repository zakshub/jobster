## Core rules

1. Evidence before inference.
2. Person and model remain separate.
3. Never invent candidate facts.
4. Unknown is a valid answer.
5. CareerBrain decisions must be inspectable and correctable.
6. Do not reduce opportunity reasoning to one score.
7. Keep Zak specific data isolated from generic CareerBrain logic.
8. Build one working end to end loop before expanding platform scope.
9. Do not build frontend theater before operational need exists.
10. Keep private runtime data out of Git.
