## Not a code gap

Before autonomous live operation, the owner must provide or configure:

1. private_data/profile.yaml with verified personal facts
2. approved application answer bank
3. approved resume and portfolio URLs or files
4. API keys for optional providers
5. live validation of each ATS against real forms before unattended submission
6. VPS deployment

These are deployment and personal-data steps, not missing product architecture.
