# Delivery Roadmap

## Phase 0 Documentation foundation

Status: active

Deliver:

1. Source of truth docs.
2. CareerBrain definition.
3. Autonomy policy.
4. Architecture.
5. Domain model.
6. Security rules.
7. Figma relationship.

Exit condition:

Implementation can begin without guessing product behavior.

## Phase 1 CareerBrain foundation

Build:

1. Structured career profile schema.
2. Evidence schema.
3. Capability model.
4. Preference model.
5. Flexibility model.
6. Compensation policy.
7. Job evaluation contract.
8. Decision record.
9. Feedback event.
10. Model update proposal.

Exit condition:

Given a manually supplied job description, Jobster can produce an explainable evaluation that Zak can correct.

## Phase 2 Discovery

Build:

1. Normalized Job model.
2. Public remote source adapters.
3. Web search adapter.
4. LinkedIn alert intake.
5. Manual URL intake.
6. Deduplication.
7. Posting snapshot.

Exit condition:

Jobster continuously collects useful remote roles into one queue without duplicates.

## Phase 3 Decision automation

Build:

1. Eligibility rules.
2. Role interpretation.
3. Fit reasoning.
4. Interest reasoning.
5. Flexibility reasoning.
6. Career value.
7. Pursuit strategy.
8. Positioning strategy.

Exit condition:

Jobster automatically rejects obvious bad matches and ranks worthwhile opportunities with explanations.

## Phase 4 Application preparation

Build:

1. Candidate answer bank.
2. Document registry.
3. Resume tailoring.
4. Cover letter policy.
5. Screening answer planner.
6. Application plan.

Exit condition:

A strong job can be turned into a complete truthful application packet.

## Phase 5 ATS execution

Sequence:

Greenhouse
then Lever
then Ashby
then Workday

For each executor:

inspect
map fields
fill
upload
validate
submit when authorized
capture receipt
handle failure

Exit condition:

Supported applications can be submitted reliably without invented answers.

## Phase 6 Continuous personal operation

Build:

1. Scheduler.
2. Retry rules.
3. Application limits.
4. Logs.
5. VPS Docker deployment.
6. Backup.
7. Health checks.

Exit condition:

Jobster operates unattended for discovery and approved application workflows.

## Phase 7 Operational frontend

Only now build the first Figma designed frontend.

Focus:

Today
opportunity review
application queue
exceptions
CareerBrain corrections
recruiter and negotiation workspace

## Phase 8 Recruiter intelligence

Build:

1. Email intake.
2. Thread context.
3. Stage classification.
4. Draft replies.
5. Interview coordination support.
6. Follow up strategy.

## Phase 9 Negotiation intelligence

Build:

1. Offer model.
2. Leverage model.
3. Counter strategy.
4. Non salary trade strategy.
5. Approval workflow.
6. Outcome learning.

## Phase 10 Productization decision

Do not start automatically.

First review personal evidence:

1. Does Jobster save substantial time.
2. Does CareerBrain improve application decisions.
3. Are submissions reliable.
4. Are recruiter responses improving.
5. Is manual intervention manageable.
6. Are other users asking for the capability.

Only then consider authentication, multiple users, hosted storage, billing, plans, onboarding, administration, and commercial frontend.
