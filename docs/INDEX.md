## Product definition

Jobster is a personal Career Agent first.

Its first job is to represent Zak career judgment closely enough to discover, evaluate, pursue, apply for, track, and negotiate opportunities with explainable reasoning.

The architecture must preserve a later path to multiple users without building SaaS infrastructure before the personal end to end loop works.
